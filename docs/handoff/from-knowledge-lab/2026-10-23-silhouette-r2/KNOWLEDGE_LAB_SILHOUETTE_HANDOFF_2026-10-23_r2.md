### 유사 개념 경계 — 일관된 것
- **rectangular / boxy / straight**: 서로 맞물립니다. rectangular = 전체 직선 외곽, boxy = 넓고 각진 비례가 뚜렷할 때 우선, straight = 하의 다리통(부분 형태). 세 값이 서로를 같은 방향으로 제외합니다.
- **A / flared / mermaid**: A = 연속 삼각형, flared = 특정 지점부터 퍼짐, mermaid = 좁은 상부 뒤 무릎 부근 큰 퍼짐(flared보다 우선). 세 값 모두 같은 우선순위를 적고 있습니다.
- **tapered / barrel / jogger**: tapered = 점진적으로 좁아짐, barrel = 바깥 곡선, jogger = 발목 밴드·커프스(겹치면 jogger 우선). 세 값이 서로를 제외합니다.
- **bootcut / straight / flared / wide**: bootcut과 flared의 "완만 vs 뚜렷" 기준이 양쪽에 같게 적혀 있습니다.
- 참고용 언급(문제 아님): `cocoon`의 `volume`, `rectangular`의 `I`·`H`는 폐기 경위 설명이고, `boxy`의 `oversized`는 핏 값과 구분하라는 설명입니다.
