## 목표별 보고서 공통 목차 (E1~E7)

1. **한 줄 결론** — 탐색적 표현 규칙(`ANALYSIS_PLAN.md` 1장)을 지킨다
2. **무엇을 검증했나** — 가설, 사전에 정한 지표·분모·신호 기준(변경했다면 변경 이력)
3. **방법** — 대상·인원·기간·도구·데이터 출처, 제외 건수와 이유
4. **결과** — 분자/분모 표, 행동 단계(L1~L6) 구분
5. **정성 근거** — 인터뷰에서 반복된 이유, 익명 인용(참가 코드만)
6. **해석 한계** — 표본 크기, 진행자 동반 영향, 의향과 실제 행동의 차이, 측정하지 못한 것
7. **2라운드에 반영할 것**
8. **증빙 목록** — 원자료 파일 이름·해시, 허가 기록(근거 종류·날짜만), 스크린샷

## 종합 BM 검증 보고서 (E0) 목차

1. 요약: 구독(B2C)·커머스 제휴(B2B2C) 각각의 초기 사업화 신호 — "더 볼 가치 있음 / 재설계 / 판단 보류"
2. 사업화 단계별 위치: 추천 품질(E7) → 실제 상품 연동(E1·E2) → 수익모델(E3·E4·E6) → PMF 신호(E5)
3. 수익모델별 근거 표: 지표 · 결과(분자/분모) · 근거 수준(L1~L6) · 한계
4. 단위경제성 요약: 실측 / 가정 구분
5. 1라운드에서 측정하지 못한 것과 이유
6. 2라운드 계획 변경 사항(가격·기능·파트너·로드맵)
7. 부록: E1~E7 링크, 사전 분석 계획 동결본, 변경 이력
