- 형식(D2): 60~75분 1회 세션이 기본. 동의한 참가자만 이후 7일 자유 사용 추적

## 1. 준비물 (세션 전날까지)

| 준비물 | 담당 | 확인 |
|---|---|---|
| 참가자 일정, 참가 코드(등록 순서대로 다음 코드) | PO | 코드·실명 대응표는 PO만 보관(Git·DB 밖) |
| 실험 빌드가 설치된 기기(참가자 기기 또는 진행자 기기) | Claude B 빌드 → PO | 연구 모드 진입 확인 |
| 참가자에게 미리 요청: 내 옷 사진 5~8벌(상의·하의·신발 포함), 사려는 옷 사진·캡처 1~2장 | PO | 얼굴이 나온 사진은 피하도록 안내 |
| 동의서(서면 또는 화면) | PO | 버전 번호 확인 |

| 녹음 기기(녹음 동의 시) | 진행자 | 파일명 = 참가 코드 |

**가격 정보 차단:** 모집 공고·안내 메시지·동의서에 가격을 적지 않는다. 진행자는 배정표 파일을 열지 않는다.

## 2. 진행 순서

| 단계 | 시간 | 진행자 말·행동(요지) | 참가자 | 기록 |
|---|---|---|---|---|
| 0. 인사·안내 | 3분 | 목적(앱 사용 경험과 의견), 소요 시간, 언제든 중단 가능, **"실험 중 가격이 보이는 화면이 있지만 실제 결제는 일어나지 않습니다"** | — | — |
| 1. 동의 | 5분 | 동의서 설명(필수: 연구 참가·사진 AI 전송 / 선택: 녹음·7일 추적) | 서명 또는 화면 동의 | 동의 항목 체크 |
| 2. 참가 코드 | 2분 | 진행자가 코드 입력 → 배정 완료 화면 확인 | — | `experiment_assigned` |
| 3. **T1 옷 등록** | 15~20분 | "가져오신 옷 사진으로 옷장을 채워 주세요. 막히면 말씀해 주세요" (먼저 도와주지 않음) | 3벌 이상 등록 | 관찰: 벌마다 성공/실패/도움 |
| 4. **T2 추천 보기** | 5분 | "오늘 입을 코디를 찾아보세요" | Styling·Looks·Today | 관찰 |
| 5. **T3 상품 추천·공식몰** | 7분 | "코디에 빠진 아이템이 있으면 살펴보세요. 사고 싶은 상품이 있으면 평소처럼 보셔도 됩니다" | Missing → 상품 → (원하면) 공식몰 | `product_*`, 관찰 |
| 6. **T4 PLUS 체험** | 10분 | "사려고 고민 중인 옷을 분석해 보세요" | 사진 1장(최대 2장) → 결과 | `plus_feature_viewed`, 관찰 |
| 7. **T5 Paywall** | 2~5분 | **진행자는 화면에서 눈을 떼고** "다음 화면을 보시고 편하게 선택해 주세요" | 고려 / 안 할래요 | `paywall_viewed`, 선택 이벤트 |
| 8. 설문 | 5분 | 설문 링크 또는 종이 | 응답 | 설문 |
| 9. 인터뷰 | 15분 | 3장 질문 | 응답 | 녹음·메모 |
| 10. 마무리 | 3분 | 7일 추적 동의자 안내, 데이터 삭제 요청 방법, 감사 인사 → 진행자가 **"인터뷰 완료 기록"** | — | `interview_completed` |

**중단:** 참가자가 원하면 즉시 중단한다. 중단 단계와 이유(말한 경우)를 관찰 기록지에 적는다. 중단한 참가자의 코드는 다시 쓰지 않는다.

**도움 원칙:** 참가자가 30초 이상 멈추거나 도움을 요청하면 "어디를 누르면 될 것 같으세요?"로 먼저 묻는다. 그래도 막히면 도와주고 **"도움"** 으로 기록한다(과업 성공에 넣지 않음).

## 3. 인터뷰 질문 (모든 그룹 같은 순서·같은 문구)

| # | 질문 | 목적 |
|---|---|---|
| I-1 | 옷 등록하면서 가장 번거로웠던 점은 무엇이었나요? | G5 |
| I-2 | 추천 코디 중 실제로 입어 볼 것 같은 것이 있었나요? 왜 그런가요? | G5·G7 |
| I-3 | 추천 상품을 보셨을 때 어떤 생각이 들었나요? 공식몰에 들어가셨다면(안 들어가셨다면) 이유는요? | G2 |
| I-4 | 사려는 옷 분석 결과가 구매 결정에 어떤 영향을 줬나요? | G3 |
| I-5 | 그 결과를 얼마나 믿으셨나요? 무엇이 있으면 더 믿을 수 있을까요? | G3 |
| I-6 | 아까 화면에서 그렇게 선택하신 이유를 말씀해 주세요 | G4 |
| I-7 | 화면에 보인 가격은 이 기능에 비해 어떻게 느껴지셨나요? (다른 가격은 말하지 않는다) | G4 |
| I-8 | 이 기능이 정식으로 나오면 실제로 결제하실 것 같나요? 어떤 조건이면요? | G4 — 의향과 실제 결제 의사 구분 |
| I-9 | 평소 옷을 살 때 망설이는 이유는 무엇인가요? | G3 |
| I-10 | 이 앱에서 꼭 있었으면 하는 기능 하나를 고른다면요? | 2라운드 |

진행자 금지 사항: 다른 가격 언급, "다른 분들은 ~했어요", 기능 장점 설득, 결제·구독이 된 것처럼 말하기.

## 5. 선택 7일 추적 (동의자만)

| 항목 | 내용 |
|---|---|
| 기간 | 세션 다음 날부터 7일 |
| 기록 | 같은 연구 이벤트(상품 노출·클릭·공식몰 이동, PLUS 재사용). 가격 실험 선택은 세션에서 이미 끝났으므로 Paywall은 다시 보이지 않는다 |
| 연락 | 시작·종료 안내 2회만. 사용을 독려하는 메시지는 보내지 않는다(행동 왜곡 방지) |
| 종료 | 7일째 종료 안내 + 원하면 계정·데이터 삭제 방법 안내 |
| 분석 | 세션 지표와 분리("7일 추적 n명 중") |
| 전제 | 서버 저장 방식이어야 의미가 있다. 운영 DB 연구 테이블이 승인되지 않으면(기기 기록만이면) 7일 추적은 종료 시 기기 내보내기를 받아야 하므로 참가자 부담을 PO가 판단한다 |
