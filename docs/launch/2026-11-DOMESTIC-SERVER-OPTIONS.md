## 2. Railway 대비 이전 작업량·영향

| 항목 | Railway(기존 계획) | 카페24 이지업(국내 VM) |
|---|---|---|
| 코드 변경 | 없음 | **없음**(같은 `Dockerfile`, `TRUST_PROXY=1`) |
| 새로 필요한 것 | 대시보드 설정 | 서버 준비 스크립트·Caddy(HTTPS)·배포 스크립트 → **이번에 `deploy/vm/`로 준비 완료**(문법 확인만, 실서버 미실행). 도메인 연결 |
| 배포 방법 | GitHub 연결 또는 `railway up` | `deploy.sh`: 이 PC에서 압축 → `scp` → 서버 빌드. **GitHub Push 불필요** |
| 작업 시간 | 반나절 | 서버 개통 후 **약 1일**(준비 0.5 + 배포·검증 0.5). 첫 빌드 수 분 |
| 메모리 | 컨테이너 8GB 상한 | 서버 8GB 전체(OS 포함) → 컨테이너 6GB 제한 + 스왑 4GB. SlimSAM 동시 1건 대기열이 있어 충분(추론, 실측 필요) |
| 자동 재시작·상태 확인 | Railway 헬스 체크 | Docker `restart: unless-stopped` + 상태 확인. 비정상(unhealthy)만으로는 재시작 안 함 → 일일 점검 |
| 로그 | Railway 로그 | `docker compose logs` — JSON 로그·grep 집계 그대로 |
| 비용 구조 | 사용량(상한 $40 필요) | **정액**(초과 트래픽만 GB당 110원, 5TB 포함이라 사실상 0) |
| 지연 | 한국→싱가포르 | 한국→일본(더 가까움, 추론) |
| 운영 부담 | 거의 없음 | OS 보안 업데이트(자동), SSH 키 관리, 만료 관리(만료 7일 후 삭제) |
| 개인정보 | 싱가포르(미국 법인) | **일본 서버** — 사진이 백엔드를 거쳐 Gemini로 가므로 처리방침·동의 문구의 국외 이전 항목 갱신 필요(출시 트랙 담당) |

## 4. 결제 전 문의 사항

### 4-1. 카페24 호스팅 고객센터 1588-3284 / 1:1 문의(help.cafe24.com)
1. 이지업 서버호스팅 **EASY C 서버 위치**(일본만인지, 한국 선택 가능한지)
2. 이지업·Node.js VPS에서 **Docker 설치·실행 가능**한지(가상화 방식)
3. **1개월 결제** 가능 여부, **설치비**, **자동연장 기본값**(꺼져 있는지)
4. **신한카드 선불카드(모두의 창업 창업활동자금 카드)로 결제 승인**되는지, 결제창의 **가맹점명**(카페24인지 PG사명인지)
5. 카드전표·주문내역에 **카페24 사업자등록번호·상품명** 표시 여부
6. 결제 후 **개통 소요 시간**
7. 80·443 포트 개방과 **Let's Encrypt 자체 설치** 가능 여부(카페24 SSL 유료 설치 없이)
8. Node.js VPS DEV C의 CPU·디스크·OS·VAT 포함 여부

### 4-2. 신한카드 1544-7000
- 모두의 창업 창업활동자금 선불카드로 **카페24(호스팅) 온라인 결제 승인** 가능 여부, 업종 제한 여부

### 4-3. 멘토기관
- 사용자 조사용 **서버호스팅 1개월 이용료(13.2만 원)**가 지급수수료(SW·클라우드 구독/기자재 임차)로 인정되는지, 증빙 형식
- (NCP 검토 시) 선불 코인 충전이 "포인트 충전"에 해당하는지(A-3)

### 4-4. 남는 해외 결제(선불카드 불가)
| 항목 | 금액 | 선택지 |
|---|---|---|
| Supabase 조사 프로젝트(Pro) | $25/월 | 자부담 / 또는 **기존 무료 QA 프로젝트를 조사용으로 전환**(무료, 대신 1주 비활성 시 일시정지 위험·E2E 환경 상실) |
| Gemini 유료 | $10 선불 | 자부담(Google은 선불카드 불가 공식) |
