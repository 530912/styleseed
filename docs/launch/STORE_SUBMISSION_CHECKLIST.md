## 6. 제출 직전 최종 확인

- ☐ 운영 빌드의 `EXPO_PUBLIC_API_URL`이 HTTPS 운영 주소인가(localhost 아님)
- ☐ 처리방침 URL이 앱·스토어 양쪽에 같은 주소로 들어갔는가
- ☐ Gemini 등급과 동의 화면 고지가 일치하는가(`EXPO_PUBLIC_GEMINI_PAID_TIER`)
- ☐ 웹 계정 삭제 페이지가 공개 주소에서 열리고 `SUPPORT_EMAIL`이 표시되는가
- ☐ 심사용 계정으로 로그인 → 분석 → 저장 → 탈퇴까지 실제로 되는가(탈퇴는 별도 테스트 계정으로)
- ☐ 스크린샷에 실제 개인정보(얼굴·이메일)가 없는가
