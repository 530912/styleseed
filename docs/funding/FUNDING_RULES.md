## 3. 증빙 (p.9, p.14~15)

| 결제 유형 | 증빙 | 근거 |
|---|---|---|
| 1건 10만 원 미만 + 가맹점명으로 사용처 확인 | 면제(카드 승인내역 갈음, 붙임1 집행 상세내역에 기재) | p.9, p.14 |
| 1건 10만 원 이상 | 건별 증빙(붙임 2) | p.9, p.14 |
| **PG·오픈마켓·간편결제**, 가맹점명으로 판매자·품목 불명 | **금액 무관** 건별 증빙 | p.9 ②, p.14, p.18 |
| 단일 50만 원 초과 | 증빙 + 기관 검토 + **멘토기관 사전승인 필수** | p.5, p.9 ③, p.14 |
| 50만 원 이하 자산성 물품 | 증빙 + 자산 보유 서약서 | p.14 |
| 여비·회의비 | 간이 증빙: 일자·목적·장소, **회의비는 동석자** 기재 | p.14 |

PG 주문상세내역서 필수 6요소(한 화면): ① 판매자 상호·**사업자등록번호** ② 주문번호 ③ 품목·수량 ④ 결제일자 ⑤ 결제금액 ⑥ 결제수단(p.15). 판매자 정보가 끝내 확인되지 않으면 **불인정**(p.15).

10만 원·50만 원 기준(p.15, p.31): 카드 승인 1건, 부가세 포함 총액. **같은 가맹점·같은 날 결제는 합산**. 같은 가맹점 기간 누적 50만 원 초과 시 전체 증빙 요청 가능. **분할 결제는 부정 집행**.
