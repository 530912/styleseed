## 1. 결제 전 (모든 건)

- [ ] 창업 아이템(STYLESEED)과 **직접 연관**이 설명되는가(p.11) — 보고서에 한 문장으로 쓸 수 있어야 함
- [ ] 비목 5개 중 어디인가(`BUDGET_ALLOCATION_2000000.md` 2장)
- [ ] 금지 항목이 아닌가: 전자기기·상품권·포인트 충전·본인/팀원 식비·주차료·취소수수료 예매(p.12, p.13)

- [ ] 거래처가 **사업자등록이 확인되는 업체**이고, 본인·가족·팀원·멘토·멘토기관·다른 진출자 관련 업체가 아닌가(p.16)
- [ ] **단일 50만 원 초과면 멘토기관 사전승인**을 받았는가(p.9, p.31) — 승인 메일·메시지 캡처
- [ ] 같은 업체 결제를 **나누지 않는가**(분할 결제는 부정 집행, p.15)
- [ ] 구독이면 **자동결제 해지 시점**을 정했는가(11.30 이후 재결제 금지, p.15)
- [ ] 판단이 애매하면 **결제 전에** 멘토기관 문의(p.24)

## 4. 결제 후 사고 처리

| 상황 | 조치 | 근거 |
|---|---|---|
| 목적 외 결제 | ① 결제 취소 → ② 불가하면 같은 금액을 쓰지 않고 잔액으로 유지 → ③ 잔액 부족 시 멘토기관 협의 | p.17 |
| 카드 승인 거절 | 사유 확인(차단 업종·해외 가맹점·취소수수료·잔액) → 개인카드로 결제해도 **지급되지 않음**(p.9 ①) | p.13 |
| 증빙 분실 | 신한카드 승인내역 + 판매처에 재발급 요청. 판매자 정보가 끝내 확인되지 않으면 불인정 | p.15 |
| 사업자 지출증빙 처리 | 금지 — 세금계산서로 부가세 환급받지 않는다 | p.9 ④, p.16 |
