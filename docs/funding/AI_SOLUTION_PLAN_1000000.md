## 1. 규정 요약

| 규정 | 근거 |
|---|---|
| 한도 **100만 원은 2개월 합계**("2개월간 총 100만원의 AI 솔루션 크레딧을 일괄 제공") | 공급기업 모집 공고(2기) / 보도자료 "1인당 100만 원의 범위" |
| 플랫폼 등록 솔루션만. 공급기업 홈페이지에서 따로 결제하면 미지원 | p.21 |
| 진출자 결제 없음 — 창조경제혁신센터 사후 정산 | p.21 |
| **1개월 단위 신청**. 1개월차 신청 **10.16~10.25** → 사용 11.1~11.30 / 2개월차 신청 **11.20~11.25** → 사용 12.1~12.31 | p.5, p.21 |
| **신청 기한 후 취소·환불 불가**, 단순 변심 취소 불가 | p.21, p.23, 공고 |
| 플랫폼 가격 = 공급기업 홈페이지 공개가(VAT 포함), 월 단위 가격 | p.22, 공고 |

## 3. 배분 계획 (가격 확인 후 확정하는 조건부 안)

| 월 | 신청 기간 | 목적 | 후보 | 예산 상한(가정) |
|---|---|---|---|---|
| **11월(1개월차)** | **~10.25(일)** | 출시 장애물 + 사용자 조사 | ① 처리방침 도구(캐치시큐) ② 아이콘·브랜딩(요비 또는 브랜딧 중 1) ③ 리서치 도구(톡키 AI 리서치 또는 리서치올 중 1) | 합계 **≤ 50만 원** |
| **12월(2개월차)** | 11.20~11.25 | 베타 피드백 분석 + 2라운드 콘텐츠 | ④ 피드백·리뷰 분석(PurplePrint 또는 Noktt) ⑤ 숏폼·이미지(빠나나·시그마인 Shorts·드랩아트 중 1~2) | 합계 **≤ 50만 원**(1개월차 잔액) |

**11월에 50만 원 이하로 묶는 이유:** 12월에는 베타 운영 중 실제 피드백·영상 수요가 생기고, 2라운드 평가(12.2~12.10) 뒤 사업화 준비에 콘텐츠가 필요하다. 1개월차에 다 쓰면 12월에 쓸 수 없다.

### 창업활동자금과의 연동

| AI 솔루션으로 해결되면 | 창업활동자금에서 줄일 항목 |
|---|---|
| 요비·브랜딧으로 아이콘·스토어 그래픽 제작 가능 | B-3 디자인 외주 30만 원 → 0원 |
| 캐치시큐로 처리방침 점검 가능 | B-4 법률 검토 25만 원 → 축소(약관·위험 조항만 검토) |
| 빠나나·시그마인으로 숏폼 제작 가능 | B-7 영상 외주 20만 원 → 0원 |

## 4. 10.25까지 할 일 (1개월차 신청 체크리스트)

1. www.modoo.or.kr 로그인 → [AI 솔루션 지원] → 2장 후보의 **월 가격(VAT 포함)**, 기능, 설명 영상 확인
2. 후보별로 기록: 무료 체험 여부, **결과물 내보내기**(이미지·문서·데이터 파일), 한국어, **데이터 처리방침**(입력한 사업계획·사용자 응답이 학습에 쓰이는지), 사용 인원 제한
3. 11월 신청 합계 ≤ 50만 원 확인 → 신청 → [내 AI 솔루션 관리]에서 현황 캡처(보고서용)
4. 공급기업이 플랫폼 밖에서 전용 요금제·혜택을 제안하면 응하지 말고 신고(modoopolice@kised.or.kr, p.22)
