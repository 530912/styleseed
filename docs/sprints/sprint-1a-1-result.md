## 3. 기존 기능 영향

- **바뀐 동작(의도):** 토큰 없이는 이미지 처리 4종을 호출할 수 없다. 분석은 로그인 없이 시간당 10회까지만 된다. 큰 요청은 413, 오래 걸리면 504·타임아웃 안내가 나온다.
- **유지:** 분석 응답 형식(box2d 보정, mask 정리), 기존 429·503 문구, 저장 실패 시 원본 사진으로 대체하는 흐름.
- **확인됨:** 로그인 토큰이 붙은 요청으로 배경 제거가 실제로 실행된다(E2E-05, 실제 SlimSAM).
- **남은 확인:** 앱 화면(`src/lib/api.ts`가 실제 세션 토큰을 붙이는지)은 Node 재현과 단위 테스트로만 확인했다. PO 확인 1번이 이것을 확정한다.

## 5. 남은 문제와 주의 사항

| 항목 | 내용 |
|---|---|
| ESLint 자동 설치 사고 | 시작 시 회귀 기준을 잡으려고 실행한 `npx expo lint`가 ESLint를 yarn으로 자동 설치해 `package.json`(devDependencies 2개)과 `yarn.lock`을 바꿨다. **두 파일 모두 되돌렸다.** `node_modules`에는 `eslint`, `eslint-config-expo`가 남아 있다(Git 추적 대상 아님). 린트 도입 여부는 별도로 정한다 |
| Guest 한도 한계 | IP 기준(IPv4·IPv6 별도 집계), 서버 재시작 시 초기화, 같은 Wi-Fi 공유. 임시 정책 |
| PRD와의 차이 | SEC-01 AC: 토큰 없는 분석 허용(임시), 익명 토큰의 이미지 처리 거절이 403이 아니라 401 |
| 실제 사진 크기 | 1A-10 완료 기준의 "실제 휴대폰 사진 3장 base64 크기 기록"은 미완료. 저장소 상품 이미지는 25~33KB로 기준에 영향 없음 |
| 앱 30초 타임아웃 | 문구만 자동 확인, 실제 중단 동작은 미확인 |
| 저장 실패 안내 화면(TS-15·16) | 문구만 자동 확인. 버튼 동작([다시 시도], [나중에] → 분석 화면 복귀)은 미확인 |
| 웹 빌드의 `Alert` | React Native Web에서는 `Alert.alert`가 아무것도 표시하지 않는다(기존 화면 전체에 해당, 이번 변경과 무관). 웹을 정식 지원하려면 별도 대응 필요 |
| `/segment-garment` | 앱에서 호출하지 않는 경로. 입력 오류를 500으로 응답(기존 동작 유지) |
| QA 프로젝트 | `styleseed-qa`를 QA 환경으로 유지한다. 실행마다 Auth 테스트 계정 2개가 쌓인다(현재 6개, 모두 테스트용). 조직의 활성 Free 프로젝트가 2개(운영 + QA)가 되었고, QA도 오래 쓰지 않으면 자동 일시정지된다 |

| 항목 | 내용 |
|---|---|
| 증상 | 흰 셔츠 사진에서 저장된 "배경 제거 이미지"가 14×16 픽셀(단추 하나)이 됨. 서버는 200을 반환하므로 앱은 성공으로 보고 BRIA 대체 경로로 넘어가지 않음 |

| 재현 | `npm run test:e2e`의 E2E-09(todo). 4개 이미지 중 1개 재현(스니커즈·로퍼·데님은 정상) |
| 영향 | 일부 사용자 옷이 단추·로고 조각 이미지로 저장됨. PRD FR-UPL-03, NFR-08(이미지 분리 품질) |
| 이번에 고치지 않은 이유 | Sprint 1A-1(인증·한도·타임아웃) 범위 밖. 이번 변경으로 생긴 문제가 아님(인증과 타임아웃만 추가) |
