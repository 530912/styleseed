## 1. Sprint 목표

> **로그인 전 분석을 그대로 유지한 채, 모든 AI·이미지 요청을 "누가 보냈는지 식별 가능한 세션"으로 처리하고, 서버를 재시작해도 유지되는 호출 한도와 보완된 데이터 접근 정책으로 사용자 데이터와 유료 API를 보호한다.**

**지켜야 할 흐름(회귀 기준):** 사진 등록 → AI 분석(로그인 없이) → 로그인/회원가입 → 옷장 저장 → Styling → Looks → Today
- 로그인 전 분석을 막거나 가입을 강제하지 않는다.
- 익명 세션은 사용자에게 보이지 않게 자동으로 만들어진다. 화면·문구는 지금과 같다.
