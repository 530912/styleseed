## 3. PO 15분 점검표 — 로그인 이후 흐름 (BUG-14)

Claude가 원격 Supabase 비밀번호를 입력할 수 없어 남은 확인이다. **진행자용 테스트 계정**으로 한다.

준비: 터미널 1 `npm run backend`, 터미널 2 `npx expo start --web --clear`(또는 Expo Go). 흰 옷 + 흰 배경 사진은 빼고, 상의 1·하의 1·신발 1 사진을 준비.

| # | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 로그아웃 상태에서 사진 선택 → 분석 → [내 옷장에 저장] | 가입 화면으로 이동 | |
| 2 | 새 테스트 이메일로 가입 | "분석한 옷을 옷장에 저장했어요" → 옷장에 1벌, **배경이 제거된 이미지** | |
