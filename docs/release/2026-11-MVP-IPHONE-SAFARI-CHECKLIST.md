## 0. 준비

- iPhone(iOS 16.4 이상), **Safari 일반 탭**. 개인정보 보호 브라우징은 탭을 닫으면 로그인·기록이 사라진다.
- 테스트용 이메일 1개(팀 테스트 주소, 개인 메일 아님). 비밀번호 6자 이상.
- 옷 사진: 앨범에 1장 이상. iPhone 카메라로 찍은 사진(HEIC) 1장 포함.
- (선택, 오류 조사용) **Mac Safari 웹 속성 검사기** 연결:
  1. iPhone **설정 → 앱 → Safari → 고급 → 웹 속성 검사기** 켬
  2. Mac Safari **설정 → 고급 → "웹 개발자용 기능 보기"** 켬
  3. iPhone을 케이블로 Mac에 연결 → Mac Safari 메뉴 **개발자용 → (iPhone 이름) → styleseed-research.pages.dev**
  4. **네트워크** 탭(요청·상태 코드), **콘솔** 탭(오류 메시지)

## 2. Gemini 미연결 때 확인할 것 (S-9 자세히)

| 확인 | 정상 | 문제 |
|---|---|---|
| 화면 | 제목 "AI 분석을 쓸 수 없어요", 버튼은 [홈으로] 하나 | "AI 서버가 혼잡해요"(옛 문구) → **새 배포가 안 보이는 것**: 새로고침, 그래도면 Claude A에 알림 |
| 시간 | 몇 초 안에 안내 | 50초 넘게 "분석 중" → 서버 응답 없음(네트워크 탭에서 `/api/analyze-clothing` 확인) |
| 네트워크 | `POST …/api/analyze-clothing` → **503**, 본문 `code: "AI_UNAVAILABLE"` | 401·403 → 로그인/익명 세션 문제, CORS 오류 → B의 허용 출처, `(failed)` → 연결 문제 |
| 반복 | [홈으로] → 다시 [옷 등록하기]로 와도 같은 안내, 앱 멈춤 없음 | 같은 화면에서 계속 오류 팝업이 뜸 |
